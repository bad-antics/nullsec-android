## 🛠️ Tools

### Kotlin Tools
- **`ApkAnalyzer.kt`** - APK static analysis
- **`ManifestParser.kt`** - Android manifest parsing
- **`PermissionAuditor.kt`** - Permission security audit
- **`ComponentScanner.kt`** - Exposed components finder

### Python Tools
- **`apk_analyzer.py`** - Comprehensive APK analysis
- **`dex_parser.py`** - DEX file parser
- **`manifest_parser.py`** - AndroidManifest.xml parser
- **`string_extractor.py`** - String resource extraction

### Frida Scripts
- **`root_bypass.js`** - Universal root detection bypass
- **`ssl_pinning_bypass.js`** - SSL certificate pinning bypass
- **`emulator_bypass.js`** - Emulator detection bypass
- **`biometric_bypass.js`** - Biometric auth bypass

### Shell Scripts
- **`adb_helper.sh`** - ADB automation helpers
- **`apk_tool.sh`** - APK manipulation wrapper
- **`logcat_filter.sh`** - Intelligent logcat filtering

## 📦 Installation

### Requirements
- Python 3.8+
- Java JDK 8+
- ADB (Android Debug Bridge)
- Frida tools
- apktool

### Quick Start
```bash
# Clone the repository
git clone https://github.com/bad-antics/nullsec-android.git
cd nullsec-android

# Install Python dependencies
pip install -r requirements.txt

# Install Frida tools
pip install frida-tools

# Run the analyzer
python src/python/apk_analyzer.py --help
```
